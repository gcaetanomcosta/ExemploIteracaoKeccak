Keccak adaptado para exibir o estado ao final de cada etapa, separando a etapa Rho da Pi. A implementação original é a versão 3.2 da implementação de Python do Keccak Team disponível em: https://keccak.team/archives.html, feito por Renaud Bauvin. A diferença entre os métodos Rounds está na separação da etapa Rho da Pi e no print do estado interno ao fim de cada etapa, sem mais alterações. Ao disponibilizar esse projeto para o exemplo, selecionei apenas os arquivos necessários da implementação original para rodar o exemplo e criei o arquivo gerarExemploIteracaoKeccak.py. Se quiserem tesar para novos valores de A, basta trocar o A nesse arquivo.
